# network-diagnostics
Free Proxy Checker — test free HTTP, HTTPS, SOCKS4 &amp; SOCKS5 proxy lists on Windows, macOS, Linux, Debian &amp; Android. Speed, anonymity (elite / anonymous / transparent), residential vs datacenter, target-site test. 18 built-in free proxy sources, 67k+ proxies. Open source (MIT) — Rust + Tauri.
